# Contributing

Pull requests welcome for:

- Better default rules in `references/food-lists.md` and `references/habits.md`
- New modes or verdict formats in `SKILL.md`, if they keep the one-screen rule
- Setup guides for other assistants and agents
- Examples in `examples/`

Please don't submit:

- Anyone's actual lab results or personal food lists
- Supplement or medication protocols
- Anything that makes the skill longer-winded. The whole point is that it answers in a few lines.

Test a change by installing the skill and sending it three photos: a menu, a fridge, a single packaged item. If the verdicts still fit one phone screen and lead with the decision, it's good.
